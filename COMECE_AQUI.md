# Clash Lara Etapas — beta0.9

Baixe o artefato Clash-Lara-Beta-APK no último workflow aprovado do branch codex/android-bluetooth-beta. Extraia e instale Clash-Lara-Etapas-Beta.apk. Envie o APK como documento pelo WhatsApp.

Todos usam o mesmo APK. Para Bluetooth: pareie nas configurações Android; anfitrião CRIAR SALA → Bluetooth; amigo ENTRAR → Bluetooth → anfitrião. Para Wi-Fi: conecte ao mesmo Wi-Fi/hotspot; anfitrião CRIAR SALA → Wi-Fi e compartilha CONVITE; amigo ENTRAR → Wi-Fi e cola. Mantenha o app do anfitrião aberto. Nenhum PC necessário.

Esta versão aparece como Clash Lara Etapas e preserva o app anterior; saves antigos não migram automaticamente. No menu da nova beta, abra TREINO POR TEMPO · VISUAIS · VOZES para treino offline, aparência e exportação de save. Veja README.md.
